## 健康风险预警模块：公开数据集推荐

针对“社区独居老人健康服务管理系统”的健康风险预警模块，我找到了**多个可直接使用的公开数据集**。以下是按匹配度排序的推荐：


### 一、MAISON-LLF 多模态传感器数据集（⭐⭐⭐⭐⭐ 首选）

这是目前**与你课题最匹配**的公开数据集，专门针对独居老年人的健康风险监测。

| 属性 | 内容 |
|------|------|
| **来源** | NIH / Nature Scientific Data |
| **DOI** | 10.1038/s41597-025-05069-7 |
| **数据规模** | 10位独居老人，连续8周，总计560天24小时传感器数据 |
| **场景** | 下肢骨折术后独居老人社区康复监测 |
| **公开状态** | 完全开源 |

**包含的数据类型**：

| 设备类型 | 采集数据 | 采样频率 |
|---------|---------|---------|
| **智能手表** | 加速度（x,y,z）、心率、步数 | 1秒 / 30分钟 / 事件触发 |
| **智能手机** | GPS位置（经纬度） | 10秒 |
| **运动传感器** | 红外运动检测 | 事件触发 |
| **睡眠监测垫** | 睡眠时长、深浅睡、鼾声、心率、醒来次数 | 每次睡眠会话 |
| **临床问卷（金标准）** | 社会孤立量表（SIS）、牛津髋/膝关节评分、TUG测试、30秒坐站测试 | 每两周 |

**为什么高度匹配你的课题**：
1. **场景完全一致**：独居老人社区居家环境，与你的系统定位吻合
2. **包含健康风险标签**：社会孤立和功能衰退的临床评估数据可作为监督学习的**ground-truth标签**
3. **多模态传感器数据**：可直接用于健康风险预警模型的训练和验证
4. **学术权威**：发表在Nature Scientific Data，已被验证可用于机器学习模型开发

**获取方式**：访问 https://www.nature.com/articles/s41597-025-05069-7


### 二、RESILIENT 老龄化共病监测数据集（⭐⭐⭐⭐ 推荐）

| 属性       | 内容                         |
| -------- | -------------------------- |
| **来源**   | UK DRI / Scientific Data   |
| **DOI**  | 10.1038/s41597-025-05958-x |
| **场景**   | 老龄化相关共病和认知衰退的多模态监测         |
| **公开状态** | 公开                         |

**核心内容**：
- 可穿戴设备和居家监测技术采集的生理、睡眠数据
- 心理健康评估数据
- 认知功能与身体活动、睡眠的相关性验证
- 可用于预测非计划住院风险的预测模型开发

**匹配度**：涵盖心理健康和认知衰退监测，适合做**心理/认知维度**的健康风险预警。


### 三、CASAS 智能家居数据集（⭐⭐⭐⭐ 行为监测）

这是智能家居行为识别领域的**经典数据集**，被广泛用于老人活动识别和异常检测研究。

| 属性        | 内容                                   |
| --------- | ------------------------------------ |
| **来源**    | Washington State University / Zenodo |
| **数据规模**  | 189个社区家庭，18年数据（2007-2024）            |
| **传感器类型** | PIR运动传感器、门磁传感器、温度传感器                 |
| **标注**    | 部分家庭有外部标注的活动标签                       |

**核心内容**：
- 数据字段：日期、时间、传感器ID、消息
- 传感器位置标识（如Bathroom、Bedroom、Kitchen等）
- 部分家庭包含楼层平面图
- 涵盖**独居老人**和**多老人家庭**场景

**为什么适合你的课题**：
- **行为模式挖掘**：通过运动传感器序列识别老人的日常生活规律
- **异常检测**：偏离正常模式的行为可作为健康风险预警的信号
- **大规模数据**：189个家庭的数据规模，模型泛化能力强

**获取方式**：访问 https://zenodo.org/communities/casas


### 四、MIMIC-IV 重症监护数据库（⭐⭐⭐ 临床数据补充）

| 属性 | 内容 |
|------|------|
| **来源** | MIT / Beth Israel Deaconess Medical Center |
| **数据规模** | 190,000+患者，450,000+住院记录 |
| **时间范围** | 2008-2019 |
| **公开状态** | 公开（需完成CITI培训认证） |

**核心内容**：
- 生命体征、实验室结果、用药记录、诊断编码
- 长期生存结局随访数据
- 可用于构建临床风险预测模型

**为什么作为补充**：
- 如果你的系统侧重于**临床健康风险**（如心血管事件、再入院风险），MIMIC-IV是理想来源
- 已有研究基于MIMIC-IV开发了老年心衰患者的预后模型


### 五、数据集对比总结

| 数据集            | 场景匹配度 | 数据类型        | 标签质量     | 规模        | 获取难度   | 推荐度    |
| -------------- | ----- | ----------- | -------- | --------- | ------ | ------ |
| **MAISON-LLF** | ⭐⭐⭐⭐⭐ | 多模态传感器+临床问卷 | 金标准（每两周） | 560天×10人  | 低（开源）  | **首选** |

| **CASAS**      | ⭐⭐⭐⭐  | 运动+门磁传感器    | 活动标签     | 189家庭×18年 | 低      | 推荐     |
| **MIMIC-IV**   | ⭐⭐⭐   | 临床EHR数据     | 生存结局     | 19万患者     | 中（需培训） | 补充     |
