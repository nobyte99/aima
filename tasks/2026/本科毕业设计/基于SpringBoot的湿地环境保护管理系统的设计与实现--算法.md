## 二、核心算法一：湿地遥感分类

### 2.1 数据源选择

| 卫星                   | 分辨率    | 时间跨度    | 适用场景                     |
| -------------------- | ------ | ------- | ------------------------ |
| **Landsat 5/7/8/9**  | 30m    | 1984年至今 | 长时序变化监测，生成湿地分类产品总体精度>90% |
| **Sentinel-2**       | 10m    | 2015年至今 | 高精度分类，白洋淀研究总体精度最高        |
| **Sentinel-1 (SAR)** | 10-30m | 2014年至今 | 穿透云雨，提供雷达后向散射特征          |

**推荐组合**：长时序分析用Landsat（30年尺度），高精度分类用Sentinel-2 + Sentinel-1（5年尺度）。

### 2.2 特征提取方法

基于白洋淀湿地的研究，多特征组合能显著提升分类精度：

| 特征类别 | 具体指标 | 重要性贡献率 |
|---------|---------|-------------|
| **光谱指数特征** | NDVI（植被）、NDWI（水体）、MNDWI（改进水体） | 40.713% |
| **SAR指数特征** | VV/VH极化后向散射系数 | 27.269% |
| **纹理特征** | 灰度共生矩阵（GLCM）—均值、方差、熵、相关性 | 32.018% |

**关键结论**：三种特征同时使用的分类精度最高。

### 2.3 分类算法选型

| 算法              | 原理         | 精度表现                      | 推荐场景        |
| --------------- | ---------- | ------------------------- | ----------- |
| **随机森林(RF)**    | 集成决策树，抗过拟合 | OA 87-94%，Kappa 0.84-0.92 | **首选**，成熟稳定 |
| **SNIC-RF**     | 超像素分割+随机森林 | 比RF精度提升0.69-5.82%         | 高精度需求       |
| **支持向量机(SVM)**  | 核函数映射高维空间  | OA 86%，Kappa 0.83         | 备选方案        |
| **深度学习(U-Net)** | 卷积神经网络语义分割 | 精度更高，但需大量样本               | 前沿探索        |

**推荐**：采用**随机森林**作为主算法，有大量权威研究支撑且工程实现成熟。

### 2.4 湿地分类体系

根据中国国家尺度湿地分类标准：

| 一级类        | 二级类                        |
| ---------- | -------------------------- |
| **自然湿地**   | 沼泽湿地（草本/木本）、湖泊湿地、河流湿地、滨海湿地 |
| **人工湿地**   | 水库、池塘、稻田、养殖塘               |
| **其他土地覆盖** | 林地/草地、耕地、建设用地              |

## 三、核心算法二：湿地变化检测

### 3.1 分类后比较法

**原理**：对两期遥感影像分别分类，对比分类结果的差异。

**输出**：转移矩阵，定量描述各类湿地之间的转换关系。

**研究案例**：若尔盖湿地1990-2020年变化分析
- 1990-2010年：湿地面积减少，湿草甸退化为高寒草地
- 2010-2020年：湿地面积略有回升

### 3.2 变化检测指标

| 指标       | 计算公式                         | 生态意义   |
| -------- | ---------------------------- | ------ |
| **变化面积** | Area₂ - Area₁                | 湿地净增减  |
| **变化率**  | (Area₂ - Area₁)/Area₁ × 100% | 变化强度   |
| **转移矩阵** | P(i→j) = 从i类转为j类的面积          | 转换方向   |
| **年变化率** | (Area₂/Area₁)^{1/n} - 1      | 年均变化速度 |

### 3.3 关键发现参考

基于中国40年湿地变化研究：
- **1980-2020年**：中国湿地总面积净减少6.09万km²（损失率12%）
- **2015年前**：湿地大幅萎缩
- **2015-2020年**：湿地略有回升
- **隐性损失**：自然湿地显著减少（草本沼泽净损失31%），人工湿地增加掩盖了真实损失

## 四、核心算法三：景观格局分析

### 4.1 核心景观指数

基于Fragstats平台，常用指数体系如下：

| 指数类别      | 指数名称    | 缩写     | 生态意义         |
| --------- | ------- | ------ | ------------ |
| **面积/密度** | 斑块密度    | PD     | 破碎化程度（越高越破碎） |
| **面积/密度** | 最大斑块指数  | LPI    | 优势斑块占比       |
| **边缘/形状** | 边缘密度    | ED     | 边缘效应强度       |
| **聚集/分散** | 聚集指数    | AI     | 同类型斑块聚集程度    |
| **聚集/分散** | 散布与并列指数 | IJI    | 不同类型邻接程度     |
| **多样性**   | 香农多样性指数 | SHDI   | 景观丰富度        |
| **连通性**   | 蔓延度指数   | CONTAG | 景观连通性        |

### 4.2 指数变化解读

白洋淀湿地生态修复效果分析：
- **修复前（2017年）**：景观趋于破碎化（PD高、AI低）
- **修复后（2022年）**：水体、挺水植物、林地连通性和聚集度提升（PD下降、AI上升）
- **机制**：退耕还淀、生态清淤、生态补水工程增加湿地面积和水体连通性

滇池湿地研究：
- **变化趋势**：2003-2023年，景观破碎度先快速增长后减缓
- **驱动因子**：人类活动是主要因素
- **演变特征**：农业用地与非湿地相互转化率达80-91%

### 4.3 计算工具

| 工具                         | 特点        | 推荐场景         |
| -------------------------- | --------- | ------------ |
| **Fragstats 4.2**          | 标准工具，指数全面 | 学术研究首选       |
| **R语言 (landscapemetrics)** | 开源可重复     | 批量处理         |

## 六、论文实验设计建议

### 6.1 研究框架

基于权威研究的方法论：

```
第1部分：湿地分类实验
├── 对比不同特征组合的分类精度
├── 对比不同算法（RF vs SNIC-RF vs SVM）
└── 输出：最优分类方案 + 精度指标

第2部分：变化检测分析
├── 多期分类结果对比
├── 计算转移矩阵
└── 输出：湿地面积变化趋势 + 类型转换规律

第3部分：景观格局演变
├── 计算多期景观指数
├── 分析指数变化趋势
└── 输出：景观破碎化/连通性变化 + 生态解读
```

### 6.2 评估指标体系

| 评估维度 | 指标 | 参考值 |
|---------|------|-------|
| **分类精度** | 总体精度(OA) | >85% |
| **分类精度** | Kappa系数 | >0.80 |
| **分类精度** | 生产者精度/用户精度 | 各类别>80% |
| **变化检测** | 转移矩阵一致性 | 对角线高值 |
| **景观格局** | 指数变化显著性 | 统计检验 |

### 6.3 创新点定位

1. **算法集成创新**：将GEE遥感分类 + 变化检测 + 景观格局分析封装为可复用的算法服务，集成到SpringBoot管理系统中
