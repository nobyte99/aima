经过长期的调研，目前对于jgty的项目，有了一个可行的简化方案，该方案预计能够完成jgty的lszhgyyh项目，该方案应由以下端点构成：
da server （dcs）  -> （社区da插件）telegraf （iotdb 写入插件）-> 代理 -> iotdb (部署3c3d1a)-> python(或telegraf读取特定iotdb的key) -> da server ? 
                                                                    ->iotdb (部署3c3d1a)-> grafana读取特定iotdb的key，执行spc分析及报警

上述方案中telegraf必须安装在windows上，其他可以安装的Linux；另外telegraf与iotdb之间应该添加代理（haproxy），从而确保集群的高可用性；iotdb通过AInode节点提供了多种时序大模型，预计能够完成流程工业的优化参数推荐。grafana提供了全套的对接iotdb的spc性能分析插件。


基础部署方案至少需要5台计算机。
